# C-Billing-Systems

A menu-driven billing system developed using C programming.

## Features

* Accepts product names, prices, and quantities.
* Calculates the total price for each product.
* Calculates the subtotal and final bill amount.
* Displays billing details in a formatted table.

## Technologies Used

* C Programming
* Arrays
* Loops
* Conditional Statements
* `printf()` and `scanf()`

## Concepts Learned

* Taking user input
* Performing calculations
* Using arrays and loops
* Displaying formatted output

## How to Run

1. Download the source code.
2. Open the `.c` file in Code::Blocks or another C compiler.
3. Compile and run the program.
4. Enter product details to generate the bill.

## Project Purpose

This project helped me improve my C programming fundamentals and practice creating a simple real-world billing application.
